# 极简设计的原则：留白不是浪费

> 大量留白、柔和阴影、圆角元素——极简风格背后是对注意力的尊重。

很多人以为极简设计是"把东西变少"。其实恰恰相反，极简是**把最重要的东西留下来**，其余的，包括装饰、颜色、阴影，都让位。

## 留白是呼吸，不是浪费

一段文字没有足够的空气，读起来就累。留白不是没设计好，而是**设计给对方喘气的空间**。

- 视线需要停顿
- 重点需要强调
- 眼睛需要休息

## 圆角让界面更"软"

直角是功能性的，圆角是人性化的。圆角元素降低了界面的攻击性，让它看起来更亲切：

```css
.card {
  border-radius: 20px;
}
```

## 柔和阴影，避免廉价感

硬阴影像贴纸，软阴影像真实的物体悬浮。关键是模糊半径要大，透明度要低：

```css
.card {
  box-shadow: 0 8px 30px rgba(0, 0, 0, 0.06);
}
```

## 五个我遵循的原则

1. **去掉能用文字表达的一切装饰**
2. **只用一个强调色**
3. **给每个区块留足呼吸空间**
4. **字体优先用无衬线，保证可读性**
5. **动效克制，从缓入缓出开始**

## 最后

极简不是把页面做成一张白纸。而是**把白纸留给真正重要的内容**。少即是多，因为它把"多"的精力，都留给了"重要"。
